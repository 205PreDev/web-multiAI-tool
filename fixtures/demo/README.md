# fixtures/demo — 데모 레일 픽스처

**완료 조건이 대표 데모 하나뿐인 프로젝트이므로 그 하나를 매번 확인합니다.** 각 단계의 산출물을 여기에 두고, 외부 API를 호출하지 않은 채 이 파일부터 아래로 흐르는 경로를 통째로 재검사합니다.

`npm run demo:rail` 한 명령으로 돌며 **비용이 0이라 매 PR에서 실행합니다.** 3단계 완료 시점부터 실질적으로 동작하고, 아직 없는 픽스처의 단계는 건너뜁니다.

## 들어올 것

| 파일 | 언제 | 무엇 |
| --- | --- | --- |
| `01_generated.glb` | 3단계 | Tripo 텍스트→메시의 실제 응답 |
| `02_cleaned.glb` | 4단계 | C-1 게이트 통과본 |
| `03_rigged.glb` | 4단계 | C-3 판정 통과본 |
| `04_animated.glb` | 5단계 | `slash` 클립과 `hit` 이벤트 포함 |
| `05_sfx_slash.mp3` | 6단계 | 효과음 |
| `06_final.glb` | 8단계 | `wmt` extras 포함 최종본 |
| `expected.json` | — | 각 단계의 판정 수치 |

C-2 서버 폴백은 대표 데모에서 발동하지 않으므로 **삼각형 15만짜리 픽스처를 따로 두어 강제로 태웁니다.** 실행되지 않는 경로는 어느 런타임에 있든 죽어 있습니다.

## 규칙

**픽스처를 바꾸는 PR은 왜 바꿨는지를 본문에 적습니다.** 픽스처 교체로 테스트를 통과시키는 것은 회귀를 지우는 것과 같습니다.
