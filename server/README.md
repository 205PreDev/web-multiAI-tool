# server

Spring Boot 서버. **아직 비어 있으며 2단계에서 세웁니다.**

## 하는 일

`docs/ARCHITECTURE.md` 1절의 목록이 정본입니다 — 인증, 크레딧 원장, 외부 API 중계, 생성 잡 큐, 정본 저장, 공유 링크, 협업 중계, 후처리 폴백.

## 하지 않는 일

**씬을 해석하지 않습니다.** 씬 리비전은 불투명한 블롭이고 서버가 아는 것은 버전 번호와 소유권뿐입니다. 도메인을 모르는 서버는 교체가 쉽습니다(`docs/REQUIREMENTS.md` 8.2절).

## 착수 전에

클라이언트는 프레임워크가 아니라 **HTTP 계약**에 대고 코딩합니다. 계약을 먼저 확정하고 구현에 들어갑니다 — `docs/ARCHITECTURE.md` 5절.

외부 생성 모델 호출은 전부 `server/adapters/registry.ts` 등록 항목만 통과합니다. 레지스트리를 우회하는 리터럴 URL은 CI가 막습니다(`CLAUDE.md` 라이선스 CI 검사).
