# client/src/ui — 디자인 시스템

**에디터와 공개 화면이 함께 쓰는 토큰과 컴포넌트입니다.** 요구사항은 N-14, 상세 규칙은 `docs/UX.md` 6절입니다.

## 의존 방향은 한 방향이다

```
editor/  ──┐
           ├──▶  ui/
site/    ──┘
```

**`ui/` 는 `editor/` 도 `site/` 도 import하지 않습니다.** 이 방향이 지켜져야 공유 뷰어가 에디터 코드를 끌고 들어오지 않습니다.

## 토큰 3층

`tokens.css` 에 primitive 와 semantic 이 있습니다.

- **primitive** — 의미 없는 값. `--p-gray-900`, `--p-space-4`
- **semantic** — 역할. `--c-surface-base`, `--c-text-muted`
- **component** — 개별 컴포넌트가 필요할 때만 만듭니다. 지금은 없습니다

**컴포넌트는 semantic 만 참조합니다.** primitive 를 직접 쓰면 테마 교체가 깨집니다.

## 테마

에디터는 다크 기본, 공개 화면은 라이트·다크 모두 지원합니다. **두 테마는 semantic 토큰의 값 교체로만 갈라집니다** — 컴포넌트 코드에 테마 분기가 나타나면 설계 위반입니다.

## 리터럴 금지

컴포넌트에 리터럴 색·치수를 쓰지 않습니다. 1단계에서 이 규칙을 린트로 강제합니다(현재는 규약으로만 지킵니다).

**토큰이 덮는 범위는 UI 크롬입니다.** 씬 안 오브젝트의 머티리얼 색과 지오메트리 치수는 사용자가 편집하는 콘텐츠이므로 토큰의 대상이 아닙니다 — 그 값들은 씬 그래프에 저장되고 glTF로 나갑니다.
