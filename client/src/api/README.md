# client/src/api — 서버 호출 단일 진입

**클라이언트의 서버 호출은 전부 이 폴더를 지납니다.** 컴포넌트에 `fetch` 를 흩뿌리지 않습니다.

2단계에서 채우며, 그전까지 클라이언트는 서버 없이 동작합니다.

## 왜 한 곳인가

- 서버 런타임 결정을 되돌릴 때 고칠 자리가 한 곳입니다(`docs/REQUIREMENTS.md` 8.2절)
- 오류 코드 → 사용자 문구 매핑(`docs/UX.md` 5절)이 한 곳에 모입니다
- 인증 쿠키·요청 ID 부착 같은 공통 처리가 흩어지지 않습니다

## 계약

`docs/ARCHITECTURE.md` 5절의 표가 정본입니다. **프레임워크가 아니라 계약에 대고 코딩합니다.**

오류 응답은 항상 `{code, message, retryable, detail?}` 이고 `code` 가 UX 문구 사전의 키입니다. 제공자 원문 오류는 사용자에게 보이지 않습니다.
