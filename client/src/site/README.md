# client/src/site — 공개 화면

로그인 없이 접근하는 화면입니다 — 랜딩, 갤러리(J-1), 공유 뷰어(J-3). **9단계에서 채웁니다.**

## 이 폴더의 제약 — 에디터를 import하지 않는다

**공유 링크를 받은 사람이 에디터 번들을 한 바이트도 내려받지 않아야 합니다.** 그래서 이 폴더는 `client/src/editor/` 를 import하지 않으며, 빌드 단계에서 두 번들이 갈라집니다.

두 번들이 공유해도 되는 것은 넷뿐입니다.

- `shared/types/`
- WMT 스키마 파서
- three.js 로더
- `client/src/ui/` 디자인 시스템 컴포넌트

## 이름에 관하여

`docs/ARCHITECTURE.md` 1절은 이 폴더를 `client/public/` 으로 적고 있지만, **Vite가 `client/public/` 을 정적 에셋 폴더로 예약**하고 있어 실제 배치는 `client/src/site/` 입니다. 같은 이름 두 개가 다른 뜻으로 존재하는 것을 피했습니다.

## 반응형

에디터와 달리 **모바일을 포함해 동작해야 합니다**(N-13). 공유받는 사람의 환경은 고를 수 없습니다.
